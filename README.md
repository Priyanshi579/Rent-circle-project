##Rent Circle is a peer-to-peer rental application designed for college students.
The platform enables students to list items such as books, electronics, calculators, sports equipment, and daily-use essentials for rent.

It promotes:

💰 Earning opportunities for students

🤝 Affordable borrowing within campus

♻️ Resource sharing and sustainability

The goal of Rent Circle is to create a trusted campus-based rental ecosystem where students can save money and generate income.
